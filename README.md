# 知衡

一个面向普通用户的认知与心理健康随访网页。当前版本支持三种标准量表、每日状态打卡、统一趋势仪表盘、规则周总结和个人数据管理。

> 本项目用于自我观察和健康教育，不提供疾病诊断、治疗建议或紧急服务。

## 当前功能

- 完整的评估前知情说明
- WHO-5 五题心理幸福感评估
- PHQ-9 九题抑郁症状筛查与标准严重程度分级
- PHQ-9 第 9 题非零回答的安全优先分流提示
- GAD-7 七题焦虑症状筛查与标准分级
- 情绪、睡眠、压力、精力、运动和备注的每日状态打卡
- 7/30 天统一状态仪表盘与规则驱动总结
- 个人记录 JSON 导出和二次确认删除
- 服务端确定性计分与输入校验
- 匿名设备标识，不要求姓名或账号
- 最近 12 次评估趋势
- 低分情况下的非诊断性进一步评估提示
- 响应式中文网页及无障碍标签
- 自动化计分测试与服务端渲染测试

## 技术栈

- React 19 + Vinext
- TypeScript
- Cloudflare D1 / SQLite
- Drizzle ORM
- Cloudflare Workers
- Node.js Test Runner

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:3000`。

## 隐私与安全

当前版本只使用随机匿名标识关联历史记录。公开演示中不应使用真实患者或研究参与者资料。在用于真实研究、医疗机构或商业环境之前，需要进一步完成伦理、法律、隐私和临床安全审查。
